Make×Slack連携でテレアポ不要！見込み客を自動検知してアポを爆速確定させる「B2B営業自動化」全手順

正直、SIerで毎日コード書いて残業して手取り20万ちょいって、まじで割に合わないんですよね。僕も最初は営業マンのリスト作成とか、死ぬほど手作業でやってて。「これ絶対AIで自動化できるだろ」ってChatGPTいじり始めたのが半年前です。

最初はAPIの設定ミスって、関係ない相手に大量のDM送っちゃうっていう大事故やらかしたこともありました。でも、そこから試行錯誤して、今はMakeとSlackを連携させて、寝てる間に商談アポが入る仕組みを作りました。先月はこれで8万円の副収入。テレアポで消耗してる人、マジでもったいないです。

今回の記事では、僕が実際に組んでいる「自動アポ取りシステム」の裏側を全部公開します。続きに全部書きました。

🤖 ChatGPT副業の最新ネタ・使えるプロンプトを毎日配信中 → https://t.me/+yUiqVJi2uNFiOTA1

ぶっちゃけ、自動化って言っても最初は泥臭いんですよ。僕も最初、Make（旧Integromat）とChatGPTを繋いで、テキトーな営業文を生成してメール送る仕組みを作ったんですけど、返信率が0.1%以下で爆死しました。内容が機械っぽすぎて、速攻でゴミ箱行きだったんですよね。

「あ、これじゃダメだ」って気づいて、ターゲットのWebサイトを巡回して「今、この会社が求人出してるから採用支援のニーズがあるはずだ！」っていうトリガーを組み込んだんです。そこからアポ率が跳ね上がりました。

じゃあ、具体的にどうやって組むのか。僕が使ってる手順をそのまま教えますね。

#

STEP1：MakeでWebサイトの変更を検知する

まずは「相手がどんな動きをしてるか」を自動でキャッチします。

1. Makeにログインして「Create a new scenario」をクリック。 2. 「HTTP」モジュールを選択し、「Make a request」を選ぶ。 3. URLに監視したい企業の採用ページURLを入力。 4. 「Parse HTML」を使って、ページ内の特定のキーワード（例：「求人」「採用」など）の変化を抽出します。

ここで失敗しがちなのが、頻繁にアクセスしすぎてIP制限を食らうこと。僕は「Sleep」モジュールを挟んで、1日1回、深夜の3時に実行するように設定してます。これでサーバーに負荷かけずにこっそり検知できます。

#

STEP2：ChatGPTで「刺さる」文面を作る

ここが一番重要です。定型文を送ると即ブロックされます。僕が使ってるプロンプトを貼っておきます。これをそのまま「OpenAI」モジュールにコピペしてください。

```text あなたは凄腕のB2B営業コンサルタントです。 以下の企業情報と採用ページの内容をもとに、相手の課題を解決する提案メールを作成してください。 ただし、以下のルールを守ること。

・「お世話になっております」等の挨拶は短くする。 ・相手が今まさに困っているであろう「採用のボトルネック」を指摘する。 ・「一度情報交換しませんか？」という軽いトーンで終わる。 ・AIっぽさを消すため、少し砕けたビジネス口調で。

企業名：{{企業名}} 抽出したキーワード：{{採用ページ内の文言}} ```

これで生成された文章を、Slackの自分専用チャンネルに飛ばすように設定します。

#

STEP3：Slack連携でアポを確定させる

自動でメールを送るんじゃなくて、一旦Slackに通知させるのがコツです。

1. Makeの「Slack」モジュールを追加。 2. 「Create a Message」を選択。 3. テキスト欄に「{{ChatGPTの回答}}」と「メール送信ボタン（またはURL）」を埋め込みます。

僕の場合、Slackに通知が来たら「これいいな」と思ったものだけ「送信」ボタンを押す運用にしてます。全自動にしちゃうと、たまに変な日本語混じったりするリスクがあるんで、最後の最後は自分の目で確認するんです。これだけで月8万の副収入なら、まあ悪くないですよね。

#

失敗から学んだ「ここだけは注意」

最初は「全部自動化だ！」と意気込んで、メール送信まで全自動にしました。でも、先月の水曜日に「求人募集中」の文言を「求人終了しました」と誤検知して、とんちんかんなメールを送りつけてしまい、クライアントから怒られたんですよね。

それ以来、「検知と生成は自動、送信は手動」というハイブリッドスタイルにしました。結局、人間が最後に確認するのが一番効率いいんです。

#

まとめ

1. MakeでWebサイトの動向を監視する。 2. ChatGPTで相手の状況に合わせた提案文を作る。 3. Slackに通知を飛ばして、最後は人間がクリックする。

これだけで、テレアポという精神的に一番キツい作業を丸ごと外注化できます。まずは自分の周りの10社くらいを対象に、テストで回してみてください。

#

次にやること

まずはMakeのアカウント作って、自分が狙いたい業界のサイトを1つだけ登録してみてください。うまくいけば、来週には「商談のお願い」メールが自分宛てに届き始めますよ。

「難しそうだな」って思ったら、まずは「HTTP」モジュールを触ることから始めてみてください。意外と、慣れればパズルみたいで楽しいんで。また面白い設定見つけたら共有しますね。
